# Walchand College of Engineering — Website

## Project Structure
wce-website/
├── index.html       ← Main HTML (structure + layout + modals)
├── style.css        ← All CSS (variables, layout, components, responsive)
├── script.js        ← All JavaScript (translations, dark mode, modals, search, chatbot)
├── images/          ← Place downloaded images here
│   └── README.txt
└── videos/          ← Place promo/bg videos here
    └── README.txt

## Features
- Sticky notice ticker
- Sticky navbar with search, language toggle (EN/Hindi/Marathi), dark mode
- Left icon sidebar + right quick-action sidebar
- 3 scroll sections: Hero, Academics/Notices/News, Placements/Campus
- Modal popups: Admissions, Departments, Research, Events, Notices, Map, Gallery
- Department filter + UG/PG/PhD tab switcher
- Chatbot with knowledge base
- Announcement popup on load
- Fully responsive (tablet + mobile)

## Usage
Open index.html directly in any browser — no build step required.
